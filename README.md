# aiqon-site

Source for the [**aIQon**](https://accilium.github.io/aiqon-site/) page — accilium's
afternoon on AI in Vienna. Season 3: Thursday, 22 October 2026, Juwel Wien.

## What this is

One static page, served via GitHub Pages. No framework, no build step, no
tracking. `index.html` holds the programme, the three live use cases and the
house rules; `assets/` holds the logo and favicon. That is the whole site.

The format in one line: AI solutions that are in operation today, shown live by
the people who built them — and how they were built. No slides, no concepts,
no vendor pitch.

## Why this repo is public

We publish how we build the consultancy, and that includes how we run our
events. Like the [aIQ blog](https://github.com/accilium/aIQ-blog), the source
and its history are part of what we share.

## Local preview

Open `index.html` in a browser. Nothing to install.

## Maintainers

Maintained by the accilium aIQ team. For corrections, open an issue.
Speaker line-ups and invitations are handled internally, not here.
