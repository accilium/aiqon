## lösungen in betrieb, vorgestellt von den menschen, die sie gebaut haben
 
aIQon ist ein ungezwungenes Get-together rund um künstliche Intelligenz. Gezeigt werden Lösungen, die heute in Betrieb sind — keine Folien, keine Konzepte, keine Vorträge. Vorgestellt von den Menschen, die sie gebaut haben, inklusive der Frage, wie: in wie vielen Tagen, zu welchen Kosten, mit welchen Fehlern. Unser Ziel ist, viel voneinander zu lernen.

Drei Live Use Cases

01 / AGENT

Ein Agent als Teammitglied

Ein Agent mit eigener Identität sitzt im Teams-Chat eines Angebotsteams: kennt den Stand, verteilt Aufgaben, meldet sich proaktiv. Live an einer öffentlichen Ausschreibung. Und: wie man so etwas baut, und was er darf.

02 / SKILLS + MEMORY

Ein Skill, der aus Feedback lernt

Ein Prüf-Skill läuft über ein Dokument. Eine Person gibt Feedback. Beim nächsten Lauf ist es drin — für alle im Unternehmen. Prozedurales Wissen, das sich verzinst.

03 / LEGACY

Legacy neu gebaut

Technische Schulden, für die nie Zeit oder Geld da war. Was passiert, wenn Datenmigration und Analytics auf einer neuen Architektur in Wochen statt Jahren entstehen.

# Jeder Use Case: Konzept erklären → live zeigen → erzählen, wie er entstanden ist. Zwanzig Minuten.

Spielregeln

  • Keine Folien, keine Konzepte. Nur Lösungen, die heute in Betrieb sind.
  • Kein Vendor-Pitch. Wir zeigen, wie wir es gemacht haben — nicht, wie Sie es machen müssen.
  • Zwei Menschen pro Bühne. Eine:r am Rechner, eine:r erzählt. Kein Moderator dazwischen.
  • Ein Raum. Talks, Pausen und Essen ohne Ortswechsel. 70 Plätze, kuratiert, auf Einladung.

Einladung

aIQon ist ein kuratierter Nachmittag für Entscheider:innen. Plätze werden auf Einladung vergeben; wer keinen Platz bekommt, sieht den Livestream. Einladungen gehen im September raus.
